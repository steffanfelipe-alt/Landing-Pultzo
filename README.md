# Pultzo landing

Static page, no build step. Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

Files: `index.html` is the scroll story (the promise, tonight's pending work, the three eras ending in the triptych, the real product screens, trust, the first flight and the founding-clinic offer, questions and the call to action). `funciones.html` lists every module. Styles and scripts are inline in each page, including the scroll-craft engine; images live in `assets/`. `BRIEF.md` records how the page was decided.

The "Pedí una demo" button opens WhatsApp with a prefilled message. Sample data on the product screens is fictional and labelled as such on the page.
